## ✨ المميزات الرئيسية للنظام

1. **إدارة المخازن المتعددة (مخزن 1 ومخزن 2):**
   * **مخزن 1 (المستودع الرئيسي):** تخزن فيه الشحنات الكبيرة الموردة.
   * **مخزن 2 (مستودع الصرف):** مخصص لتحويل الدفعات إليه لتسهيل الصرف اليومي.
   * واجهة متكاملة لعرض المجموع الكلي المدمج لكافة المواد بالعدد والباج.

2. **نموذج الجرد الفعلي (Inventory Reconciliation):**
   * إمكانية قيام أمين المخزن بإجراء جرد دوري بالضغط على زر **جرد ✍** لتحديث الرصيد الفعلي في أي مخزن، مع تدوين الفروقات تلقائياً بالسجل.

3. **التحويل والصرف الذكي:**
   * **التحويل:** نقل سهل للمواد من مخزن 1 إلى مخزن 2 بنقرة زر مع إدخال الكمية.
   * **الصرف المباشر:** صرف مباشر من مخزن 1 أو مخزن 2 إلى الزبائن (شعبة القسطرة أو المناقلات).
   * **اعتماد الطلبات:** تظهر طلبات الزبائن معلقة في لوحة الأدمن، ويقوم الأدمن باعتمادها وتحديد مصدر الصرف (مخزن 1 أو 2)، ليقوم النظام بخصمها تلقائياً بالاعتماد على **مبدأ FIFO (الأقدم صلاحية يخرج أولاً)** لضمان الاستهلاك السليم للمخزون.

4. **نظام التنبيهات المبكر:**
   * تنبيهات تلقائية ملونة للمواد التي تقل صلاحيتها عن **6 أشهر** مع عد تنازلي بالأيام والأشهر.

5. **خوارزمية التخمين والتنبؤ بالهدر (Forecasting):**
   * تقوم الخوارزمية بحساب متوسط الاستهلاك الشهري الفعلي بناءً على سجل الطلبات المصروفة، وتقارنه مع المدة المتبقية لصلاحية الدفعات الحالية وتكشف عن **كميات الهدر المتوقع تلفها قبل الصرف** وتصدر تنبيهات حيوية مثل "خطر هدر كبير" لتنبيه الإدارة لنقلها أو استهلاكها سريعاً.

* البرنامج يعمل كصفحة واحدة ذكية (Single Page Application) ولا يحتاج لخوادم خارجية أو قواعد بيانات معقدة (يتم تخزين البيانات بشكل آمن وتلقائي في متصفحك عبر `LocalStorage`).
* لتشغيله: قم بفتح ملف `index.html` في أي متصفح ويب (Chrome, Edge, Firefox).
* للبدء السريع، تم تضمين بيانات ومواد طبية وحركات سابقة حقيقية لتوضيح قدرة التنبؤ فور التشغيل!
